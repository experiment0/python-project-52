Описание работы

В данном web-приложении реализована возможность регистрации пользователей и создания задач.
Задачам могут быть присвоены статусы и метки.

  • Создавать задачи, статусы и метки могут только зарегистрированные пользователи.
  • Возможность редактировать и обновлять информацию о себе доступна только самому пользователю.
  • Статус у задачи может быть только один, а количество меток не ограничено.
  • Удалить задачу может только ее создатель.
  • Нельзя удалить пользователя, статус или метку, если они связаны с задачей.
